# Quick start and setup

## Get to the first card in two minutes

1. Gather at least two players.
2. Choose **New game**, then select the device topology.
3. Enter every player, including multiple people sharing one device.
4. Select a profile and intensity comfortable for the whole group.
5. Each person or shared device configures boundaries.
6. Verify the names in the lobby and let the host start.

## Choose a device topology

### Couch mode

Use Couch when only one device is available or everyone is watching one TV. Names,
cards, votes, and controls all appear on that screen. No phone is required.

### Personal devices

Use personal devices when everyone should have cards and controls on their own device.
The host creates a Room; everyone else opens the link, enters the code, and joins as a
player.

### Party Screen

Use Party Screen for a shared TV plus personal devices. Join the TV as a display. It
shows public state but is not a second host and never receives private boundaries.

## Agree before starting

Discuss expected duration, a group-safe intensity, whether adult content is wanted,
and the rule that anyone may skip without explanation. Decide who hosts first and who
could take over. The best intensity is one where everyone participates freely, not the
highest available setting.
