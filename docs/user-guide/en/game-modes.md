# Game modes and cards

## Classic Truth or Dare

The active player chooses Truth or Dare. The server selects a compatible card after
applying profile, intensity, boundaries, and history. Resolve it, then move on.

## Random Truth or Dare

The game chooses the type using the configured ratio and limits long streaks. Use it
when the group does not want a choice prompt every turn.

## Never Have I Ever

Only suitable yes/no questions appear. Each controlled player votes for themselves;
the public result is aggregated. A shared device can submit each of its local players'
votes in turn.

## Let's Talk

Conversation cards appear after the configured number of normal questions. They create
space for discussion rather than competition. Normal questions continue if the
conversation-card pool is exhausted.

## Actions

- **Another card / Veto:** rejects the current card and records it so it does not
  immediately return.
- **Skip:** serves the same safety goal; no explanation is required.
- **Next:** resolves the current card or result.
- **End game:** ends the authoritative session for every connected device.

If no card satisfies every active rule, the card pool is exhausted. Never weaken
someone's boundaries silently; end the round or let the group deliberately choose a
less restrictive profile for a new session.
