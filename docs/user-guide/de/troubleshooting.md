# Probleme lösen

## Raum wird nicht gefunden

- Code erneut Zeichen für Zeichen prüfen; `0`, `1`, `I` und `O` werden nicht verwendet.
- Sicherstellen, dass alle Geräte dieselbe Serveradresse benutzen.
- Bei mehreren Runden im Netz den Code mit dem Host vergleichen.
- Der Raum kann abgelaufen oder der Server neu gestartet worden sein.

## Verbindung bricht ab

Lass die Seite geöffnet und warte auf die automatische Wiederverbindung. Nach der
Rückkehr gilt der neue Server-Snapshot; nicht mehrfach auf eine alte Aktion tippen.
Wenn der Host länger ausfällt, übernimmt nach der Schonfrist ein Spielergerät.

## Start ist deaktiviert

Es müssen mindestens zwei Personen vorhanden sein. Lokale Personen zählen mit. Prüfe,
ob Namen gespeichert wurden und ob alle nötigen Grenzen bestätigt sind. Nur der
aktuelle Host kann starten.

## Keine passende Karte

Der Kartenpool kann erschöpft sein, wenn Sprache, Profil, Intensität, Grenzen und
Verlauf zusammen keine veröffentlichte Karte übriglassen. Fehlende Übersetzungen werden
standardmäßig nicht durch anderssprachige Karten ersetzt. Beende die Runde oder ändere
vor einer neuen Sitzung bewusst Profil/Intensität; entferne niemals Grenzen unter
Druck.

## Ton fehlt

Browser erlauben Ton oft erst nach einer bewussten Interaktion. Tippe einmal auf die
Seite und prüfe die Präsentationssteuerung, Gerätelautstärke und Stummschaltung. Die
Runde bleibt auch ohne Ton vollständig spielbar.

## Problem bleibt bestehen

Notiere Serverversion, Uhrzeit, Raumcode (aber **keinen** Gerätezugang), Rolle,
Browser/Gerät und den sichtbaren Fehlercode. Diese Angaben helfen der betreibenden
Person, Serverprotokolle einzugrenzen, ohne geheime Zugangsdaten offenzulegen.
